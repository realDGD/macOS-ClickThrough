日期：2026-10-16。用户授权发布未公证的 v0.1.0 开发版、新建独立 `realDGD/homebrew-tap` 并补充安装及发布说明；不安装或启动新包，不替换当前运行实例。

## 本地准备证据

- 原有本地二进制中检出源码绝对路径，因此不作为公开归档上传。
- 新构建加入编译器源码路径映射，并只在新组装副本上移除调试符号，再进行 ad-hoc 签名。
- 新二进制个人路径模式命中为 0，公开 ZIP 的资源、版本、SHA-256 和所检查的个人路径／凭据模式通过校验。
- 六项发布校验测试、现有五项分发检查及真实 Homebrew DSL 解析通过；未安装应用、未注册本地 tap 或修改 TCC／登录项。

原始检查与状态快照保存在本地 `app/verification/20261016-release-vzg1r1v7/`，新验证包在 `app/build/release-v0.1.0-validation/`。本地包仅用于检查；公开包将由 tag 对应的 GitHub runner 构建。
