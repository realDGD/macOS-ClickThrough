## 图标与 API

运行状态统一使用 `cursorarrow.click` / `cursorarrow.click.2`。本机 Apple `CoreGlyphs.bundle` 的 `name_availability.plist` 标注其从 macOS 11 引入，`name_aliases.strings` 将其对应到 macOS 26 起的新名称 `pointer.arrow.click` / `.2`。当前系统实际创建两种旧名称图像成功；16 pt regular 配置仍得到 19×20 pt 图像。

[Observation](https://developer.apple.com/documentation/observation/observable())、[Bindable](https://developer.apple.com/documentation/swiftui/bindable) 和 [NSApplication.activate()](https://developer.apple.com/documentation/appkit/nsapplication/activate()) 要求 macOS 14；[SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice) 要求 13。现有完整产品代码以 14 为最低目标构建成功；没有为更早系统替换这些 API。
