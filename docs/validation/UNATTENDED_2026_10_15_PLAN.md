# 无人值守测试与研究

授权：用户暂时离开电脑，要求继续长时间的其他测试和方向探索。

## 本轮范围

1. 对当前运行的 ClickThrough 做约 30 分钟进程资源观察：存活、RSS、进程 CPU 时间、文件描述符数量。保留原运行二进制，不重新授权、不改登录启动或其他工具配置。
2. 对实际核心代码做确定种子压力与策略不变量检查，测量匹配／过滤／激活编排自身的成本。与 AX IPC、真实事件分派和业务延迟严格区分。
3. 在隔离目录检查发布打包、校验值、Cask 生成及失败输入；不安装软件、不注册 tap、不发布远端。
4. 调研登录启动识别、SMAppService 状态、系统停用 event tap 与 AX 超时语义，给出现有保证与后续实验建议。

测试源与结果放在 `app/verification/20261015-unattended/`；研究报告放在 `docs/validation/`。现有源、二进制与实验日志的证据边界继续适用。若发现可复现的问题，先记录和复现，再做最小修复；不为测试而扩展产品架构。

## 验收边界

- 当前尚未获得用户对正式应用 AX 授权完成的反馈，不能把权限失败路径或自动化等同于运行中真实点击。
- 用户物理点击业务回归仍待执行，不以新建／重放鼠标事件代替。
- 不 raise 方向保持暂停；不扩展应用名单、不安装浏览器；不做退出登录、重启、睡眠、TCC 撤权等会改变用户环境的测试。
- 运行观测完成与产品长期稳定是不同结论；30 分钟只能支持本轮观测条件下的资源记录。
