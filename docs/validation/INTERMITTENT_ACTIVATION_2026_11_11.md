# 间歇性窗口激活异常：诊断准备

日期：2026-11-11，Asia/Makassar。

## 用户报告与已采集证据

用户报告微信和 Chrome 偶尔无法通过点击激活，红绿灯不亮；另一台显示器上的窗口可点，点击 Codex 后曾恢复。当时受影响显示器只有这两个窗口，尚不能确定整屏范围。随后 Chrome 再次出现三次点击才激活，用户明确前两次红绿灯未亮。

运行包为 0.1.3 (6)。已通过现有设置开启本地诊断。15:09:42.916 的 Chrome 请求记录窗口 AXMain 和应用 AXFrontmost setter 均返回成功，总处理耗时约 9.7 ms，但即时 AXFrontmost 读回为 false。此读回不是激活完成屏障，不能单凭它认定该次点击失败的原因，也不能将这条请求对应为完整的三次点击。

现有日志在窗口命中和筛选之后才记录请求，因此没有请求记录不能证明点击未进入回调。未见本次会话的 `tap_disabled` 记录；随后监听器快照为开启，2 秒线程采样主要在主 RunLoop 等待，未抓到持续阻塞。这些事后状态不排除先前瞬时阻塞。原始会话快照、采样与监听器状态保留在本地 `app/verification/intermittent-focus-20261111/`，不进入源码提交。
