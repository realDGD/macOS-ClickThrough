# 不 raise：一次性 AX 按钮实验

**已由用户暂停，保留为未来探索。探针已退出，不自动恢复。** 未来目标允许短暂切换焦点，但不允许窗口前移；该变体未验证。暂停状态见 [STATUS.json](STATUS.json)。以下是历史使用说明。

可丢弃 PoC，macOS 27；独立于原 A4。先读 [API 调研与实验边界](../../docs/research/BACKGROUND_ACTION_RESEARCH.md)。

只捕获填写 PID 的一个跨应用后台普通左键单击。其他应用点击照常通过；目标已前台、修饰键点击、非普通窗口层不在首轮范围。捕获后原始 down/up 均不投递给目标；松开时撤下 tap，再用 AX 命中与公开 AXPress 执行一次。不激活、不 raise、不重放、不重试或降级。

捕获后拖动超过 4 个屏幕点会取消；停止时若还按着左键，先消费配对 up 再撤下监听。该阈值仅是一次性普通单击实验边界，不代表生产拖动策略。退出程序前先松开鼠标。未找到 AXPress 按钮时本次不执行，界面明确提示；不能把它解释成单击已经通过。

按钮子元素最多向上检查 6 个 AX 对象，只按按钮角色和声明动作判断，不读取按钮名称或业务文字。AX 消息超时 250 ms（每次消息），所有 AX 工作发生在 tap 已撤下后；不能据此声称性能达标。

原生旧靶标的自绘 AXGroup 不提供 AXPress，保持不变。首轮只用现有 Chrome 诊断页的普通按钮。独立网页业务日志证明操作是否执行；探针的前台 PID、窗口 ID 顺序及有限延后快照用来判断前台／叠放是否变化。采样之间的瞬间窗口变化不能由快照排除；同时参考激活通知与用户观察。

准备：`bash poc/background-action/build.sh`。产物为本地 ad-hoc 签名，不放入 `/Applications`。原 A4 不重新构建。测试前必须暂停原 A4，避免混合引擎。

每轮：准备一次 → 点击 Codex 作为前台来源 → 单击后台 Chrome 普通按钮一次 → 松开即自动停止。返回看计数和窗口状态，不再追加点击“补成功”。只报告本次是否恰好 +1、Chrome 是否前移／变前台。

2026-10-15 已有首个用户标注结果：Chrome 普通按钮 2→3、不前移、Codex 仍前台，对应探针 trial 4。一次 AXPress 与一次网页操作配对，四次前台／顺序采样一致。早期 trial 1 曾使 Chrome 激活，控件身份未知，仍保留为限制。详见 [研究结果](../../docs/research/BACKGROUND_ACTION_RESEARCH.md)。不重复普通按钮试次，真实代码复制尚未验证。

后续真实网页复制已验证为失败：网页试次 2 有效不匹配，对应探针 trial 13。AXPress 返回 0、前台及叠放保持，但用户看到要求 ChatGPT 处于焦点的剪贴板错误；不能宣称达到 A4 的复制效果。结果和全部原始日志保留，未开展临时焦点或 PID 投递试次。
