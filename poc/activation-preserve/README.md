# Phase 1 A：激活后放行真实事件的临时探针

这是可丢弃的实验代码，不是正式应用架构。最低系统为 macOS 27；以 Swift 6 编译。验证 A1 / A2 / A3 / A4，不包含 AXPress、鼠标模拟或事件重投。

2026-10-15 状态：本轮实验已停止，A4 源码和产物保留，Firefox 已清理，原始日志保留。当前结果见 [已有测试结论](../../docs/research/PHASE_1_RESULTS.md)；下文历史“待测／继续”内容不构成当前任务，不再新增目标或重复试次。

- **基线**：建立 Session 主动 tap，但不激活目标，返回同一个原事件。
- **A1**：使用公开 NSWindow 屏幕命中与 CGWindow 元数据获得 PID，仅调用 NSRunningApplication.activate。
- **A2**：使用公开 AX 命中及 AXWindow 关联，确认 AXMain 可写、设置成功后调用应用激活；AX 步骤失败时不退回 A1。
- **A3**：创建应用级 AX 对象，检查 AXFrontmost 可写后只设置 true；不设置 AXMain、不调用普通 activate、不重试、不回退。单对象消息超时设为 25 ms，不代表总回调延迟上限。
- **A4**：先使用 A2 的公开命中窗口 AXMain 步骤，成功后执行 A3 的 AXFrontmost 步骤。同应用已前台时仍处理命中窗口；不调用普通 activate，不回退、不重试、不补击。两步分别记日志，实际操作仍需用户物理输入验证。

当前仅对正常窗口层、无键盘修饰键的左右 down 请求激活；down/up/drag 均原样放行。修饰键和非正常层窗口记录后放行，尚不属于本轮覆盖。A1 对同应用非 key 窗口没有专门处理。多屏坐标和异常窗口命中仍待实测。

`@preconcurrency import ApplicationServices` 用于 Swift 6 与 SDK 中未标注线程安全的 C 常量互操作，不是旧 macOS 回退。tap 加在主 RunLoop；回调在其同步上下文通过 MainActor 执行观察，原 CGEvent 不跨线程投递。

原生 **FirstClickTarget** 是独立进程。左侧默认拒绝 first mouse，右侧接受；只有靶标收到完整 down/up 后操作计数才增加。右键记录实际菜单打开及选项执行，计数不由引擎日志决定。

浏览器靶标提供普通按钮计数、链接、输入框、原生上下文菜单及复制验证。每次复制测试先点击“准备复制试次”，将剪贴板替换成不同的对照标记，防止残留正确内容造成假阳性；这一步明确显示在界面中。粘贴时只保存匹配布尔值，不保存原文。

返回浏览器粘贴是读取结果：先激活 Chrome，再点击验证输入框，确认出现插入光标后按 Cmd+V。输入框可再次点击以获得焦点；一次点击限制只针对被测后台复制按钮。未收到 paste 事件不能解释为复制失败。页面显示匹配提示，不显示剪贴板原文。

构建：`bash poc/activation-preserve/build.sh`。产物使用本地 ad-hoc 签名，仅用于实验，未公证或分发。

只启动、编译和授权，不算 first-click 通过。运行结果与真实鼠标试次由 [Phase 1 记录](../../docs/research/PHASE_1_A_SESSION.md) 保存；原有 24 项矩阵不因 PoC 编译通过而标为已通过。

2026-10-14 的真实鼠标对照：Codex 复制在 observe/A1/A2 下均匹配；以 Codex 为前台来源时，自有 AppKit 拒绝首次点击靶标在完全停止/A1/A2 下均未执行，正对照均各执行一次。将前台来源改为探针本身后，同一 A1 使拒绝靶标执行。追加 A3 后，探针在后台、Chrome/Codex 分别前台时，拒绝靶标均收到原 down/up 并各执行一次。即刻 AXFrontmost 读回仍为 false，不能把该读值当操作验收或同步屏障。浏览器作为目标、其他框架和组合鼠标语义仍待验证，不据此确定正式架构。

随后 Chrome 和 Safari 分别作为后台目标的对照：停止时普通按钮不执行、输入框不能直接输入；A3 时按钮独立计数 +1，用户确认输入框首次点击后能直接输入。右键在停止/A3 下均有效。Firefox、复制业务与组合输入仍待测。

真实 ChatGPT 网页复制后续对照：同一 Chrome 窗口内 trial 10/11、两个 Chrome 窗口间 trial 30/31，均为停止有效不匹配、A3 有效匹配。原生右键菜单选项在停止/A3 下均执行一次；双击 click count 1/2 和拖出取消也已局部确认。同应用另一个后台窗口的输入仍有空缺：A3 对已 frontmost PID 直接放行，用户反馈验证框需要两次点击；继续独立窗口级实验。
